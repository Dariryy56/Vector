## Запуск

Требуется Node.js, совместимый с установленной версией Vite.

```bash
npm install
npm run dev
```

Откройте URL, который выведет Vite в терминале. Команды проверки:

```bash
npm run lint
npm run build
```

## Основные части

- `src/App.jsx` — состояние редактора, библиотека, добавление/дублирование/удаление объектов и экспорт SVG.
- `src/components/Sidebar.jsx` — библиотека компонентов и управление слоями.
- `src/components/Canvas.jsx` — холст, выделение, перемещение и трансформации объектов.
- `src/components/ExtractionDialog.jsx` — выбор объектов внутри загруженной SVG-иллюстрации.
- `src/utils/svg.js` — разбор SVG, базовая очистка входного SVG и формирование экспортируемого SVG-документа.
- `src/assets/illustrations/` — встроенная библиотека исходных иллюстраций.

Пользовательские компоненты сохраняются в `localStorage` текущего браузера. Экспорт композиции выполняется только в SVG.



### Архитектура

Приложение реализовано как клиентский веб-сервис на React и Vite.

**Хранение исходников.** Исходные SVG расположены в src/assets/illustrations/ и загружаются при сборке проекта как текстовая разметка. Пользователь также может импортировать SVG-файл через интерфейс.

**Извлечение компонентов.** Модуль src/utils/svg.js разбирает SVG с помощью DOMParser, выполняет базовую очистку входной разметки и находит доступные группы и векторные фигуры. Выбранные элементы копируются вместе с необходимой родительской SVG-структурой и связанными определениями. Для каждого компонента сохраняются название, исходный файл, содержимое SVG и viewBox.

**Хранение и повторное использование.** Пользовательские компоненты хранятся в состоянии React и сохраняются в localStorage браузера. На холсте хранятся ссылки на компоненты библиотеки и параметры их размещения: координаты, размер и угол поворота.

**Формирование композиции.** Холст отображает компоненты как SVG-элементы. Их порядок в массиве объектов определяет порядок наложения слоёв.

**Экспорт.** Модуль src/utils/svg.js формирует самостоятельный SVG-документ, включающий векторную разметку всех размещённых элементов и их трансформации. Результат скачивается как файл .svg.

Состояние холста автоматически не восстанавливается после перезагрузки страницы; готовая композиция сохраняется через экспорт SVG.
