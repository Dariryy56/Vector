# SVG Composer

React-веб-сервис для сборки и редактирования SVG-композиций из заранее подготовленных векторных компонентов. Композиция собирается из исходной библиотеки: сервис не генерирует новые иллюстративные объекты. SVG остаётся векторным, а элементы можно перемещать, пропорционально масштабировать, поворачивать, дублировать и упорядочивать по слоям.

## Демо и исходный код

- **Работающий сервис:** https://svg1vector.netlify.app
- **Репозиторий:** https://github.com/Dariryy56/Vector
- **Примеры готовых SVG-композиций:** папка `example/`

### Короткая демонстрация

В сервисе можно проверить основной сценарий работы:

1. Ввести метафору или заголовок, например «учёба», либо указать названия компонентов через запятую: `Книга, Ручка, Телефон`.
2. Проверить автоматически размещённые объекты, а затем при необходимости переместить их, изменить размер пропорционально, повернуть, дублировать или изменить порядок слоёв.
3. Выбрать размер иллюстраций L или S, формат холста и цветовую схему.
4. При необходимости импортировать собственную SVG-иллюстрацию или JSON-палитру.
5. Экспортировать композицию в SVG и открыть полученный файл в векторном редакторе.

## Возможности

- **Библиотека SVG.** Встроенная библиотека формируется из SVG-файлов в `src/assets/illustrations/`. Можно также импортировать дополнительные SVG-файлы в библиотеку приложения.
- **Два размера детализации.** Для подготовленных компонентов доступны варианты L и S. При переключении размера приложение использует соответствующий исходный SVG, если он есть.
- **Главные и фоновые варианты.** Для компонентов, у которых подготовлены оба варианта, можно переключать роль между главным объектом и фоновым. Новые иллюстративные объекты не создаются.
- **Автоматическая сборка.** Сервис подбирает компоненты по метафоре/заголовку на основе локального словаря тематик и синонимов. Также можно указать названия компонентов вручную. Это подбор по правилам, а не универсальное понимание произвольного текста нейросетью.
- **Редактирование холста.** Поддерживаются перемещение, пропорциональное масштабирование, поворот, дублирование и удаление объектов, блокировка положения и изменение порядка слоёв. На холсте можно разместить до 100 объектов.
- **Форматы холста.** Квадратный - `1000 × 1000`, вертикальный - `800 × 1200`, горизонтальный - `1200 × 630`. При переключении формата существующие объекты сохраняются; их расположение автоматически не перестраивается. Фоны «Линии» и «Рабочий стол» имеют подготовленные варианты для разных форматов.
- **Цветовые палитры.** Встроены три схемы: фиолетовая, персиковая и бирюзовая. Можно импортировать палитру в формате JSON и удалить пользовательскую палитру. Перекраска применяется к распознаваемым цветовым ролям исходной библиотеки и не изменяет геометрию SVG.
- **SVG-экспорт.** Композиция экспортируется в единый SVG-документ с размером холста, фоном, расположением объектов, поворотами и порядком слоёв. Элементы не растрируются.

## Запуск локально

Необходимы Node.js версии 20.19+ или 22.12+ и npm.

```bash
npm ci
npm run dev
```

Открыть адрес, который Vite выведет в терминале. По умолчанию это `http://localhost:5173/`.


## Структура исходной библиотеки

Для автоматического сопоставления вариантов компонентов по размеру и роли используются каталоги `L основа`, `L фон`, `S основа` и `S фон`. Соответствующие варианты одного компонента должны иметь одинаковое имя SVG-файла.

Поиск SVG осуществляется рекурсивно во всех вложенных каталогах. Нераспознанные папки не препятствуют загрузке библиотеки, содержащиеся в них SVG добавляются как самостоятельные элементы без автоматического сопоставления вариантов L/S.

## Архитектура: хранение, получение и повторное использование элементов

### Хранение

Исходная библиотека находится в `src/assets/illustrations/` и версионируется вместе с проектом.
При запуске Vite импортирует встроенные SVG как исходный текст, после чего `library.js` формирует из них библиотеку компонентов.
Импортированные пользователем SVG-компоненты сохраняются в `localStorage` текущего браузера.
Импортированные палитры, выбранная палитра и название композиции также сохраняются в `localStorage`.
Расстановка объектов на холсте не сохраняется автоматически между перезагрузками. Для сохранения результата предназначен экспорт SVG.
Сервер и отдельная база данных для работы текущего прототипа не используются.

### Получение компонентов

При выборе размера и роли приложение обращается к библиотеке и определяет подходящий подготовленный SVG-вариант. Поиск по названию использует названия компонентов и таблицу синонимов. Подбор по метафоре использует локальный набор тематических правил, которые сопоставляют слова и темы с компонентами библиотеки.

При изменении цветовой схемы приложение сопоставляет известные исходные цвета с цветовым ролям палитры. Цвета, которые не входят в заданное сопоставление, могут остаться без изменений.

### Повторное использование и экспорт

Каждый объект на холсте это отдельный экземпляр компонента из библиотеки. Для него хранятся идентификатор компонента, координаты, ширина и высота отображения, угол поворота, роль и состояние блокировки. Дублирование создаёт ещё один экземпляр существующего компонента, а не новый иллюстративный объект.

При экспорте приложение формирует SVG-документ с размером холста и размещёнными компонентами. SVG-разметка компонентов встраивается в итоговый документ; позиционирование и поворот задаются векторными трансформациями. Растровое изображение вместо SVG не создаётся.

## Основные модули

- `src/App.jsx` - состояние редактора, управление холстом, импорт компонентов и палитр, автоматическая сборка и экспорт.
- `src/components/Canvas.jsx`- SVG-холст, отображение элементов, их перемещение, масштабирование и поворот.
- `src/components/Sidebar.jsx` - библиотека компонентов, автоматическая сборка и список слоёв.
- `src/components/Icon.jsx`- вспомогательные интерфейсные иконки.
- `src/utils/library.js` - формирование библиотеки и выбор вариантов SVG по размеру, роли и формату.
- `src/utils/composition.js`- расчёт размеров и автоматическая раскладка компонентов.
- `src/utils/metaphor.js` - поиск компонентов по названиям, синонимам и тематическим правилам.
- `src/utils/palettes.js` - встроенные палитры, проверка JSON и перекраска известных цветовых ролей.
- `src/utils/svg.js` - разбор SVG, подготовка разметки и формирование файла экспорта.
- `public/palette-example.json` - пример JSON-палитры для импорта.
- `tests/`- автоматические тесты утилит поиска, раскладки, палитр и SVG-экспорта.

## Импорт своей палитры

1. В панели «Цветовая гамма» нажмите кнопку `+`.
2. Выберите JSON-файл палитры. За основу можно взять `public/palette-example.json`
3. При успешной проверке палитра добавится в список и применится к композиции. У палитры должен быть уникальный `id`, поле `name`, `version: 1` и группы цветов `objects` и `background` с ролями `object1`–`object4` и `background1`–`background4`. Все цвета должны быть HEX-кодами формата `#RRGGBB`.
4. Пользовательскую палитру можно удалить из списка; три встроенные палитры удалить нельзя.

## Ограничения прототипа

- Подбор по метафоре ограничен словарём и тематическими правилами в `src/utils/metaphor.js`. Неизвестная формулировка может не дать результата.
- Перекраска работает с известными цветами, сопоставленными с ролями исходной палитры. Произвольные цвета из сторонних SVG не обязательно будут автоматически перекрашены.
- Пользовательские SVG и импортированные палитры хранятся локально в браузере, а не в общем серверном хранилище. Они не переносятся автоматически в другой браузер или на другое устройство.
- Композиция на холсте автоматически не сохраняется между перезагрузками, её нужно экспортировать в SVG.
- Проект не обращается к внешнему AI API во время работы. Автоматический подбор компонентов выполняется локальным кодом.

## Инструменты ИИ


**Инструменты ИИ, использованные при разработке.** ChatGPT использовался в качестве вспомогательного инструмента для обсуждения архитектурных решений, анализа кода, а также поиска и исправления ошибок. В работающем сервисе обращения к внешним ИИ-сервисам и API не выполняются. Подбор компонентов по метафоре основан на локальном словаре тематик и синонимов. Генерация новых иллюстративных объектов не производится, композиции формируются из подготовленных SVG-файлов библиотеки.
